# Mitt wes120v-prosjekt

Dette er et lite Vite-prosjekt som en del av en obligatorisk oppgave "1". Det inneholder kun en enkel index.html uten demo-innhold.

## Forutsetninger for oppgaven
Du må installere eller ha installert:
- Node.js
- pnpm

## Installasjon:
Kjør følgende kommando i prosjektmappen din: 
- pnpm install

## Utviklingsserver:
Start med følgende kommando:
- pnpm dev

Vite viser deretter en lokal adresse i terminalen, for eksempel: 
- http://localhost:5173/
Du kan åpne denne i nettleseren for å se prosjektet.

## Refleksjon
I denne oppgaven lærte jeg hvordan man setter opp et Vite-prosjekt, bruker pnpm og jobber med Git på en mer strukturert og hensiktsmessig måte. Jeg har også fått en bedre forståelse av hva som er forskjellen mellom save, commit og push. Save lagrer filen lokalt i editoren, mens commit tar et slags "snapshot" av endringene som har blitt gjort i Git. Push sender commitene som har blitt gjort i det lokale repositoryet til det remote repositoryet på GitHub. Jeg har i tillegg lært forskjellen mellom lokal og remote: det lokale er den delen som foregår på min egen maskin, mens remote er den versjonen som ligger på nettet på Github.

Git historikken gjør det slik at det er enkelt å se hva som har blitt endret, når det skjedde og hvem det var som gjorde det. Jeg ser også viktigheten av gode commit-meldinger, fordi de forklarer hvorfor endringer ble gjort, ikke kun hva som ble endret. En utfordring som jeg støtet på i oppgaven var en merge-konflikt i README som jeg løste ved å fjerne Git sine konfliktmarkører og beholde den teksten jeg ønsket. Samtidig hjalp det meg å forstå hvorledes Git markerer forskjeller mellom ulike brancher. Alt i alt føler jeg at har fått en bedre forståelse av Git og hvordan man jobber med brancher og merges.
